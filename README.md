## 🚀 Live Demo on GitHub Pages (Free Hosting)

You can host this portfolio directly on GitHub for free:
1. Go to your repository settings: [Settings → Pages](https://github.com/syedaamish11/personal-portfolio/settings/pages)
2. Under **Build and deployment** → **Branch**, select `main` and root `/ (root)`.
3. Click **Save**.
4. In about 60 seconds, your site is live at:
   👉 **`https://syedaamish11.github.io/personal-portfolio/`**

## ✨ Features

- **Responsive Design**: Adapts cleanly across mobile phones, tablets, and desktop displays with custom hamburger navigation.
- **Modern Dark UI**: Sleek glassmorphism contrast with accessible typography (`Inter` & `JetBrains Mono`).
- **Interactive Project Showcase**: Direct links to open-source GitHub repositories with responsive hover states.
- **Clipboard Utility**: One-click "Copy Email" with animated toast notification.
- **Scroll Spy & Back-to-Top**: Active navigation section tracking with IntersectionObserver and floating scroll button.
- **Zero Heavy Frameworks**: Pure vanilla HTML5, CSS3, and JavaScript for maximum performance and instant load times.
