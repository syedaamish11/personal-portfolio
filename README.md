## 🚀 Live Demo on GitHub Pages (Free Hosting)

You can host this portfolio directly on GitHub for free:
1. Go to your repository settings: [Settings $\rightarrow$ Pages](https://github.com/syedaamish11/personal-portfolio/settings/pages)
2. Under **Build and deployment** $\rightarrow$ **Branch**, select `main` and root `/ (root)`.
3. Click **Save**.
4. In about 60 seconds, your site is live at:
   👉 **`https://syedaamish11.github.io/personal-portfolio/`**

## ✨ Features

- **Responsive Design**: Adapts cleanly to mobile phones, tablets, and desktop displays.
- **Modern Dark UI**: Sleek contrast with accessible typography (`Inter` & `JetBrains Mono`).
- **Interactive Project Showcase**: Direct links to open-source GitHub repositories.
- **Zero Heavy Frameworks**: Pure vanilla HTML5, CSS3, and JavaScript for maximum performance and instant load times.
